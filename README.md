# ONE MORE FLOOR

A one-touch endless tower arcade game in the **One More** series.

## Game loop
Enter a floor, survive a 3–8 second challenge, reach the elevator, hear the ding, and go up. Death is followed by an immediate **ONE MORE?** restart.

## Modes
- **Endless** — escalating procedural sequence built from fair, validated floor templates.
- **THE 100 FLOORS** — deterministic daily seed; everyone gets the same 100-floor sequence for the date.

## Floor mechanics
Static and moving spikes, moving platforms, collapsing tiles, disappearing platforms, sweeping laser, rotating hazard, pursuing wall, low-ceiling precision jump, bounce pads, timed switch/door, dark floor, double-speed floor, mystery modifiers, coin floors, and boss floors.

## Quality-of-life
Forgiving collision margins, coyote time, jump buffering, stable swept landing checks, local best score, unlockable accent themes, synthesized sound/haptics, offline service worker, and a first-run tutorial.

## Android
The repository-level `one-more-floor-android.yml` workflow packages this folder with Capacitor and publishes `one-more-floor-debug.apk` as a workflow artifact and GitHub release asset.
